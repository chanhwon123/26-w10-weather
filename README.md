# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

> **한국폴리텍대학 강서캠퍼스 사이버보안과 1학년 「웹콘텐츠 제작」 10주차 실습 과제**  
> Google Antigravity IDE를 활용하여 구현 계획(Implementation Plan) 수립, 컴포넌트 모듈화, 외부 공개 API(Open-Meteo) 연동, 사이버보안 체크포인트 분석 및 듀얼 배포를 완성한 프로젝트입니다.

## 1. 소개

Open-Meteo의 실시간 기상 관측 및 대기질 모델 API를 기반으로 전 세계 주요 도시의 날씨와 미세먼지 농도를 한눈에 파악할 수 있는 **스마트 기상 & 대기질 대시보드**입니다.

### 🌟 주요 핵심 기능
- **실시간 날씨 카드 (`CurrentWeather.jsx`)**: 현재 기온, 체감 기온, 상대 습도, 풍속, 강수량 및 `lucide-react` 동적 기상 아이콘, 주야간(낮/밤) 식별 뱃지 제공.
- **통합 대기질 카드 (`AirQualityCard.jsx`)**: 한국 환경부 4단계 기준(좋음, 보통, 나쁨, 매우 나쁨)에 따른 미세먼지(PM10) 및 초미세먼지(PM2.5) 수치, 게이지 바 및 단계별 건강 권고사항 안내.
- **24시간 시간별 기온 예보 (`HourlyChart.jsx`)**: 외부 무거운 라이브러리 없이 순수 경량 SVG로 구현된 24시간 시간대별 기온 변화 꺾은선 차트 (최고/최저 기온 포인트 및 3시간 단위 시계열 표시).
- **7일간 주간 일기예보 (`WeeklyForecast.jsx`)**: 향후 1주일간의 요일별 기온 범위(최저~최고 막대 게이지), 날씨 상태 아이콘 및 강수 확률(%) 표시.
- **400ms 디바운스 도시 검색 (`CitySearch.jsx`)**: Open-Meteo Geocoding API를 연동하여 한글 및 영문 도시명 검색, API 남용 방지 400ms 디바운스, 자동완성 드롭다운 지원.
- **주요 도시 프리셋 & 최근 본 도시 (`CitySelector.jsx`)**: 8대 주요 도시 빠른 선택 버튼 및 `localStorage` 기반 최근 검색 도시 저장/삭제 뱃지 제공.
- **온도 단위 변환 토글**: 섭씨(°C)와 화씨(°F) 간 실시간 전환 지원.
- **날씨 상태별 동적 테마**: 맑음, 흐림, 비, 눈, 주야간 상태에 따른 은은한 비주얼 그라데이션 배경 테마 자동 적용.

## 3. 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo API의 특징**:
  - WMO(세계기상기구) 표준 기상 관측 모델 및 대기질 분석 데이터를 제공하는 완전 공개(Public) API입니다.
  - 회원가입이나 Secret Key 발급 절차 없이 무료로 호출 가능하므로 클라이언트 단독 실습에 적합합니다.
- **API 통신 로직(`src/api/weather.js`) 모듈 분리 이유**:
  - **관심사 분리(Separation of Concerns)**: UI 컴포넌트(렌더링 및 인터랙션)와 데이터 페칭 및 가공 로직(네트워크 통신, WMO 코드 변환, 환경부 등급 판정)을 명확히 분리함으로써 코드의 가독성과 재사용성을 극대화했습니다.
  - **유지보수성 향상**: API 엔드포인트 URL이 변경되거나 캐싱 계층이 도입되더라도 UI 컴포넌트를 수정할 필요 없이 `src/api/weather.js` 한 곳에서만 대응할 수 있습니다.
- **도시 검색 시 디바운스(Debounce, 400ms)의 필요성**:
  - 검색창에 "London"을 입력할 때 `L`, `o`, `n`, `d`, `o`, `n` 각 글자마다 요청을 보내면 단 1~2초 만에 6회 이상의 불필요한 네트워크 트래픽이 발생합니다.
  - 이는 클라이언트 측 리소스 낭비뿐만 아니라, 외부 API 서버에 DoS 형태의 부하를 주게 되어 `429 Too Many Requests (Rate Limit Exceeded)`로 인해 사용자의 IP가 차단될 위험이 있습니다.
  - 타이핑이 완전히 멈춘 뒤 400ms 이후에만 1회 호출하도록 **디바운스**를 적용하여 서버 부하를 최소화하고 안전한 통신을 보장했습니다.

## 4. 보안에서 확인한 것 (사이버보안과 체크포인트)

- **공개 API(Public) vs 비밀 키 API(Private/Secret)의 취급 차이**:
  - Open-Meteo는 데이터 자체가 공개용이므로 클라이언트(React)에서 직접 호출해도 보안상 안전합니다.
  - 그러나 결제 모듈(Stripe, 토스페이먼츠 등), LLM 유료 API, 사내 데이터베이스 API처럼 **Secret Key나 마스터 토큰이 필요한 서비스는 절대로 프론트엔드 코드에 포함해서는 안 됩니다.**
- **클라이언트 직접 호출의 보안 위협과 BFF(Backend For Frontend) 패턴**:
  - 프론트엔드(브라우저)에서 시크릿 키를 사용하면 브라우저 개발자 도구의 Network 탭, 자바스크립트 빌드 번들(`.js`), 또는 메모리 덤프를 통해 100% 탈취당합니다.
  - 키가 유출될 경우 막대한 금전적 과금 피해(API 요금 폭탄)나 데이터베이스 무단 탈취 사고가 일어납니다.
  - **해결책 (BFF 프록시)**: 반드시 안전한 백엔드 프록시 서버(Express, NestJS, Next.js API Routes, Cloudflare Workers 등)를 구축하여, 프론트엔드는 백엔드 프록시와만 세션 기반 통신을 수행하고, 비밀 키는 서버 환경변수(`.env`)에 안전하게 은닉하여 백엔드에서만 외부 API를 호출해야 합니다.
- **HTTPS와 혼합 콘텐츠(Mixed Content) 방어**:
  - 배포 사이트가 안전한 `https://` 보안 통신을 사용할 때, 내부에서 암호화되지 않은 `http://` API를 호출하면 브라우저의 동일 출처 및 전송 보안 정책(CSP / Mixed Content Policy)에 의해 통신이 강제 차단됩니다.
  - 이는 중간자 공격(MITM, Man-In-The-Middle)으로 인해 기상 데이터가 위변조되거나 스니핑되는 것을 브라우저가 원천 차단하기 위한 필수적인 보안 메커니즘입니다. 본 프로젝트의 모든 엔드포인트는 `https://` 프로토콜을 사용합니다.

## 6. 커스터마이징한 부분

1. **날씨 및 주야간(is_day) 기반 동적 비주얼 테마 (옵션 A)**:
   - 기상 상태 코드(맑음, 흐림, 비, 눈)와 주야간 여부에 따라 대시보드 전체 배경 그라데이션이 은은하고 자연스럽게 전환되도록 CSS 테마를 구축했습니다.
2. **최근 본 도시 `localStorage` 저장 및 뱃지 관리 (옵션 B)**:
   - 사용자가 검색하거나 선택한 도시 목록을 브라우저 로컬 스토리지에 최대 5개까지 자동 저장하고 상단 뱃지로 노출하여, 클릭 한 번으로 이전 도시의 날씨를 즉각 재조회할 수 있도록 구현했습니다. (개별 삭제 및 전체 삭제 지원)
3. **섭씨(°C) / 화씨(°F) 실시간 단위 변환 토글 (옵션 D)**:
   - 현재 기온, 체감 온도, 24시간 시간별 기온 차트, 7일간 최고/최저 기온 모두 사용자의 선택 단위(°C ↔ °F)에 맞춰 실시간 환산 표시되며, 선택된 단위는 `localStorage`에 자동 보관됩니다.
4. **순수 경량 SVG 꺾은선 차트 & 주간 기온 바**:
   - 무거운 외부 차트 라이브러리(Chart.js, Recharts 등)에 의존하지 않고, React의 수학적 상태 계산과 SVG 태그(`<polyline>`, `<circle>`, `<polygon>`)만을 활용하여 번들 크기를 최적화하고 뛰어난 반응성을 확보했습니다.
